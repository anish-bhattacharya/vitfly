# 蒸馏训练结果对比分析

生成时间: 2026-05-05

## 概述

本报告对比分析了 Branch C、D、E 三个 Mamba 变体的知识蒸馏训练结果。所有分支均使用 ViTLSTM 作为教师模型，训练 50 个 epoch。

## 训练配置

| 配置项 | 值 |
|--------|-----|
| 教师模型 | ViTLSTM (`/root/vitfly/models/ViTLSTM_model.pth`) |
| 训练轮数 | 50 epochs |
| 损失权重 | α=1.0 (GT loss), β=1.0 (distill loss), γ=1.0 (gap penalty) |
| 初始化方式 | 随机初始化 (init_from_bc=false) |

## 性能对比

### 验证集指标

| 分支 | 参数量 | Best Val Score ↓ | Val Loss (GT) ↓ | Distill Gap ↓ |
|------|---------|------------------|------------------|----------------|
| **Branch D** | 2,595,699 | **0.02584** | **0.01727** | 0.01714 |
| **Branch E** | 2,191,603 | 0.02735 | 0.01877 | 0.01716 |
| **Branch C** | 2,411,387 | 0.02757 | 0.01879 | **0.01756** |

### 关键发现

1. **最佳性能**: Branch D 在验证集上表现最好
   - 最低的 val_score (0.02584)
   - 最低的 ground truth loss (0.01727)
   - 参数量最大 (2.6M)

2. **参数效率**: Branch E 参数量最少但性能居中
   - 仅 2.19M 参数
   - Val score 0.02735，比 Branch D 高 5.8%
   - 蒸馏 gap 与 Branch D 相当

3. **蒸馏质量**: Branch C 的蒸馏 gap 最小
   - Distill gap 0.01756
   - 说明学生模型与教师模型输出最接近
   - 但 GT loss 略高于其他分支

## 技术细节

### 蒸馏损失函数
```
Total Loss = α × L_GT + β × L_distill + γ × L_gap
```
- L_GT: 学生模型与真实标签的损失
- L_distill: 学生与教师输出的 KL 散度
- L_gap: 惩罚学生与教师输出差异过大

### 参数量对比
- Branch D (2.6M) > Branch C (2.4M) > Branch E (2.2M)
- 参数量差异约 18% (最大 vs 最小)
- 性能差异约 6% (Branch D vs Branch C)
