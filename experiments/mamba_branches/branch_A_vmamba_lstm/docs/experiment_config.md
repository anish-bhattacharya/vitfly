# 分支 A: VMamba + LSTM 实验配置清单

## 1. 模型架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    输入层                                    │
│  深度图 (B, 1, 60, 90) + 速度 (B, 3) + 四元数 (B, 4)          │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│              VMamba 视觉编码器                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Patch Embedding: Conv2d(1→dim, 4×4, s=4)            │    │
│  └─────────────────────────────────────────────────────┘    │
│                            │                                 │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ VSS Block × depth                                   │    │
│  │  - LayerNorm → SS2D(2D 选择性扫描) → Residual        │    │
│  │  - LayerNorm → MLP(4×dim→dim) → Residual            │    │
│  └─────────────────────────────────────────────────────┘    │
│                            │                                 │
│  ┌─────────────────────────────────────────────────────┐    │
│  │ Global Pool + FC(dim → 512)                         │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    特征融合层                                │
│  concat [视觉特征 (512), 速度/10(3), 四元数 (4)] = 519       │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                  LSTM 时序建模                               │
│  LSTM(input=519, hidden=128, layers=2)                     │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    输出层                                    │
│  FC(128 → 3) → 3D 线速度命令                                 │
└─────────────────────────────────────────────────────────────┘
```

## 2. 超参数配置表

### 2.1 基础配置
| 参数 | 默认值 | 搜索范围 | 说明 |
|------|--------|---------|------|
| embed_dim | 64 | [48, 64, 96] | VMamba 嵌入维度 |
| depth | 4 | [2, 4, 6, 12] | VSS Block 层数 |
| d_state | 16 | [8, 16, 32] | SSM 状态维度 |
| lstm_hidden | 128 | 固定 | LSTM 隐藏层大小 |
| lstm_layers | 2 | 固定 | LSTM 层数 |
| dropout | 0.1 | 固定 | Dropout 率 |

### 2.2 训练配置
| 参数 | 值 | 说明 |
|------|-----|------|
| 优化器 | AdamW | β1=0.9, β2=0.999 |
| 学习率 | 1e-3 | 余弦退火调度 |
| Warmup | 5 epochs | 线性预热 |
| Batch Size | 32 | 根据显存调整 |
| Epochs | 50 | 或至收敛 |
| 梯度裁剪 | 1.0 | 防止梯度爆炸 |

### 2.3 消融实验配置
| 实验 ID | embed_dim | depth | d_state | 预期参数量 |
|--------|-----------|-------|---------|-----------|
| A_exp01 | 48 | 2 | 8 | ~400K |
| A_exp02 | 64 | 4 | 16 | ~700K |
| A_exp03 | 96 | 6 | 32 | ~1.1M |
| A_exp04 | 64 | 12 | 16 | ~1.5M |
| A_exp05 | 64 | 4 | 32 | ~800K |

## 3. 硬件环境说明

### 3.1 最低要求
- **CPU**: 4 核心以上
- **内存**: 8GB+
- **存储**: 10GB 可用空间

### 3.2 推荐配置
- **GPU**: NVIDIA RTX 3060+ (12GB 显存)
- **CPU**: 8 核心以上
- **内存**: 16GB+

### 3.3 软件环境
```yaml
python: 3.8+
pytorch: >=1.13
einops: 0.8.0
cuda: 11.7+ (可选)
```

### 3.4 依赖安装
```bash
# 核心依赖
pip install torch torchvision einops

# 可选 (GPU 加速)
pip install mamba-ssm causal-conv1d
```
